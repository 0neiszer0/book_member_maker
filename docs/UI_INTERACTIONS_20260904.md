# 조 이동·일정 입력 개선 (2026-09-04)

## 변경 사항

- PC: 이름을 잡아 끌면 이름 카드가 커서를 따라오고, 원래 자리와 도착 조를 표시합니다.
- 모바일: 320ms 길게 누른 후 이동합니다. 빠른 스와이프는 일반 스크롤로 남깁니다.
- 조 밖에 놓기, Escape, 포인터 취소 시 배정은 바뀌지 않습니다. 화면 가장자리 자동 스크롤, 클릭 이동·실행 취소를 유지합니다.
- 공지 PNG에서 성별·발제자 설명 문구를 제거했습니다. 이름 색상·굵기와 한 줄 명단은 유지합니다. 신규 결과/과거 기록에 같은 캡처 함수를 사용합니다.
- 운영 개요 제목 굵기를 공통 글꼴의 800으로 맞췄습니다.
- 학기 생성 후 생성된 학기로 이동하여 날짜별 도서·저자·안내와 목/월 사회자를 함께 입력합니다.
- 날짜를 오가도 초안이 남고, 일정 하나 또는 변경한 일정 전체를 저장할 수 있습니다. 저장 성공 시 카드 요약이 즉시 갱신됩니다.
- 붙여넣기는 날짜 검증 후 초안만 채웁니다. 잘못된 행이 있으면 어느 행도 채우지 않습니다. 빈 셀은 기존 내용을 지우지 않습니다.
- 사회자 미정 상태로 일정 저장은 가능하며 Word 다운로드 전 필수 입력은 유지합니다.

## 저장·보안

- 스키마 변경이나 DB 마이그레이션은 없습니다. 운영 DB는 이 작업에서 수정하지 않았습니다.
- 기존 관리자 인증과 사회자 CSRF 토큰을 사용합니다. 다른 주차의 사회자 변경 및 중복 회차는 쓰기 전에 거부합니다.
- 주차 도서는 기존 목/월 회차, 발제문, 연결된 기록 동기화를 유지합니다. 출석·조 편성 알고리즘은 변경하지 않았습니다.
- 여러 테이블/일정 저장은 단일 트랜잭션이 아닙니다. 중간 실패 시 일부 반영 가능성을 명시하고, 성공한 일정만 저장 완료로 표시합니다. 실패한 입력은 유지되어 재시도할 수 있습니다.

## 검증

- Python 전체 235개 통과.
- Node: 조 편성 상태, 드래그 이벤트, 일정 초안, 기존 명단 입력 경합 테스트 통과. CI에도 등록.
- 실제 로컬 브라우저: PC 드래그(8/8 → 7/9), 실행 취소, 만남 기록 갱신, PNG 렌더 확인.
- 320/390/768/1024/1440px: 일정 입력 본문 가로 넘침 없음, 모바일 세로 배치, 개요 제목 computed font-weight 800 확인.
- 실제 DOM에 합성 터치 이벤트를 전달하여 긴 누름 미리보기, 이동 중 배정 유지, 드롭 후 2/2 → 1/3, 미리보기 제거, 빠른 스와이프 미차단 확인.
- 날짜별 초안 보존, 두 일정 일괄 저장, 잘못된 날짜 전부 차단, 붙여넣기 빈 칸 보존을 로컬 브라우저에서 확인.
- 물리적인 iPhone/Android 기기에서의 터치 검증은 수행하지 않았습니다.
- 이 문서는 배포 전 구현·검증 기록입니다. 배포 결과는 해당 커밋의 GitHub Actions와 Render 배포 이력에서 확인합니다.
