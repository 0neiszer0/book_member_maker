## 확인한 현재 구조

- 학기별 명단과 전체 계정 정보는 이미 별도 테이블/저장 경로다. 학기 상태를 바꿔도 계정 권한은 바꾸지 않는다.
- 도서·일정·사회자, 발제문, 회차 출석, 학기 출석은 이미 학기/회차 ID를 갖는다.
- 현재 학기 메뉴에서 전체 운영 화면으로 넘어가야 하는 기능이 많아 맥락이 끊긴다.
- 공지/자유게시판 URL의 term_id는 현재 탐색 맥락일 뿐, 글의 소속 학기를 구분하지 않는다.
  따라서 메뉴 이름만 ‘학기 공지’로 바꾸면 잘못된 기대를 만든다.
- 벽돌책/소모임/특별행사와 동아리방은 학기를 넘겨 진행될 수 있다.

1. 학기 강의실 운영 메뉴에 ‘도서·일정’, ‘발제문 관리’, ‘출석·조 편성’, ‘학기 참석 현황’을 배치.
2. 각 화면에서도 같은 학기 이름/메뉴를 유지하고, 다른 학기로 갈 때 선택한 학기를 명시.
3. 전체 운영에는 모든 학기로 들어가는 입구와 전체 계정/통계를 남긴다.
