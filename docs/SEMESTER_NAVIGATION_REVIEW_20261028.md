# 학기별 운영 구분 검토안

사용자 요청 4번의 검토 및 구현 진행 문서다. 사용자는 아래 메뉴 정리를 승인했고,
추가로 공지를 전체 공지와 학기별 공지로 나누도록 요청했다. 로컬 구현과 기능 검증을 마쳤으며 공개 배포는 미승인이다.
요청 1~3번(공유 이미지, 과거 강의실, 학기별/전체 회원 관리)도 로컬 구현·검증을 마쳤다.

## 확인한 현재 구조

- 학기별 명단과 전체 계정 정보는 이미 별도 테이블/저장 경로다. 학기 상태를 바꿔도 계정 권한은 바꾸지 않는다.
- 도서·일정·사회자, 발제문, 회차 출석, 학기 출석은 이미 학기/회차 ID를 갖는다.
- 현재 학기 메뉴에서 전체 운영 화면으로 넘어가야 하는 기능이 많아 맥락이 끊긴다.
- 공지/자유게시판 URL의 term_id는 현재 탐색 맥락일 뿐, 글의 소속 학기를 구분하지 않는다.
  따라서 메뉴 이름만 ‘학기 공지’로 바꾸면 잘못된 기대를 만든다.
- 벽돌책/소모임/특별행사와 동아리방은 학기를 넘겨 진행될 수 있다.

## 추천하는 구분

| 기능 | 학기 강의실 안 | 전체 운영 |
|---|---|---|
| 회원 | 해당 학기 활동·휴식·종료, 명단 승계 | 전체 회원 정보, 로그인/운영진 권한, 중복 계정 |
| 세미나 운영 | 해당 학기 도서·일정·사회자, 발제문 접수·제출 현황 | 학기 생성·선택, 전체 운영 개요 |
| 출석·조 편성 | 해당 회차 예정 명단·출석 확정·불참·조 편성, 학기 충족 현황·내보내기 | 전체 기간 통계/기록 조회 |
| 공지·게시판 | 전체 공지 + 해당 학기 공지 표시 | 전체 공지와 학기별 공지 관리, 자유게시판 유지 |
| 기타 활동·시설·계정 | 관련 링크만 제공 | 동아리방, 세미나실, 벽돌책/소모임, 행사, 가입·계정 연결, 설정 |

### 이번에 추가로 옮기기 추천

1. 학기 강의실 운영 메뉴에 ‘도서·일정’, ‘발제문 관리’, ‘출석·조 편성’, ‘학기 참석 현황’을 배치.
2. 각 화면에서도 같은 학기 이름/메뉴를 유지하고, 다른 학기로 갈 때 선택한 학기를 명시.
3. 전체 운영에는 모든 학기로 들어가는 입구와 전체 계정/통계를 남긴다.
4. 기존 주소는 계속 동작시킨다. 메뉴 이동만으로 권한을 넓히거나 데이터를 복제하지 않는다.

### 이번에는 분리하지 않기 추천

- 자유게시판·후기 게시판: 이번 추가 분리는 공지에 적용하며, 다른 게시판은 기존 범위 유지.
- 행사·벽돌책·소모임·시설 예약: 학기 경계를 넘는 활동이어서 전체 운영 유지.
- 과거 명단 자동 확정: 실제 참석과 정식 학기 등록은 다르므로 자동 생성하지 않는다.

## 과거 기록 처리 (요청 2번)

운영 DB에는 2026년의 3개 학기와 2025년부터의 확정 세미나 기록이 있다.
2026년 1~2월 7개 세미나는 등록된 학기 날짜 범위 밖이다.
이런 자료는 기존 기간별 키를 보존하되 실제 기록 날짜로 이름을 붙이고,
클릭하면 본인의 날짜·도서·확정 참여 및 공유 후기 링크가 나오는 읽기 전용 강의실로 표시한다.
기존 학기 카드와 같은 크기/색상 띠/제목/내역 버튼을 사용한다. DB의 과거 출석/가입 명단은 수정하지 않는다.
