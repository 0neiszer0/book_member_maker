- 출석: 참석한 열만 걸러내던 필터 제거. 본 세미나 결석·확정 대기·예정과 선택 활동의 참여 기록 없음 구분.

- 과거 학기: 확정 history의 회원 ID 또는 동명이인이 없는 이름만 근거로 표시. 학기가 없는 연도는 기록 카드.
  학기 가입/이수 사실을 새로 생성하지 않는다. 숨김은 회원별 DB 설정, 다시 표시 가능.

  기존 글은 plain, 새 서식 글만 HTML 허용 목록으로 정제. 외부 이미지·스크립트·임의 스타일 불허.

## 알림·푸시

모든 회원의 종 메뉴·읽음 상태·알림 페이지. 알림 링크의 로그인 후 복귀 경로도 유지.
가입/계정 연결/불참 신청은 임원에게, 처리 결과는 해당 회원에게, 미제출 발제문은 활동 회원에게,
미작성 후기는 실제 출석이 확정된 참가자에게 알림. 완료/마감된 할 일은 주기적 갱신으로 종료.

`bookmembers-notifications.timer`가 부팅 2분 후 및 작업 종료 5분 후 실행. 웹 요청 중 전체 할 일을 계산하지 않는다.
동일 이벤트/회원의 알림은 중복 생성하지 않는다. 푸시는 기기별 발송 기록으로 중복 억제하고 404/410 구독 제거.
일시 오류는 15분 간격 최대 3회 뒤 다음 날 재시도. 작업당 발송 최대 100개, 동시 실행 flock 차단.
전송 호스트는 알려진 브라우저 Push 서비스만 허용하고 리다이렉트 금지. 구독·키는 서버 전용 테이블에 저장.
화면 잠금 알림에는 회원 이름/신청 내용을 넣지 않고 ‘책반우 새 알림’만 표시한다. 누르면 해당 활동으로 이동.
사이트 HTML/API를 오프라인 캐시하지 않는다. iOS는 홈 화면 설치 앱에서 사용. OS/브라우저의 알림 허용이 필요.
VAPID 키는 승인 후 root 전용 app.env에 생성. 기존 키는 재생성하지 않음. 개인 Gmail에 의존하지 않는다.
