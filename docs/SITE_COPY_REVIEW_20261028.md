# 사이트 문구와 탭 로고 정리

상태: **로컬 검증 완료, 운영 반영 승인 전**. 운영 앱은 여전히 `62249f6`, Worker는 `762caede-8d06-4a67-82e1-3eac6cee04af`다.

## 수정 범위

- 위키 14개 문서를 읽고 13개 문서 수정안을 작성했다. 대문의 검토용 초안/준비 중 꼬리말, 과거 네이버 카페 안내 배경, 미확정 항목을 작성하지 않았다는 해설, 2026년 예시를 정리했다. 동아리방 안내는 유지했다.
- 추가 세미나를 매주 열리는 활동처럼 설명하던 문구를 필요시 개설하는 안내로 고쳤다. 학기 안내는 실제 강의실 메뉴와 전체/학기 공지 사용 방법으로 바꿨다.
- 회원/관리자 이용 안내의 오래된 요일·날짜·정책 예시와 Render 운영 설명을 정리했다. 발제문 수정은 로그인 계정 또는 수정 코드라는 실제 동작에 맞췄다.
- 캘린더·출석·과거 참여 기록·활동 관리 등의 중복 설명과 구현 용어를 줄였다. 브라우저 알림 불가 상태는 준비 중이라는 표현 대신 현재 상태와 대체 행동을 안내한다.
- 임시저장≠제출, 투표/조 편성≠확정 출석, 예약 충돌, 계정/개인정보 보호 등 실제 행동에 필요한 안내는 보존했다. 운영진 전용 안내와 개발 주석을 회원 화면의 불필요한 문구로 혼동하지 않았다.
- 기존 메뉴의 흰색 책 모양과 빨강을 재사용한 SVG/32px PNG 파비콘을 모든 독립 HTML head에 연결했다. 공개 CDN 허용 목록에는 정확한 두 파일만 추가했다. 권한·업무 규칙·레이아웃 변경은 없다.

## 검증

- 관련 Python 테스트 30개 통과: 정적 파일 manifest/허용 목록, 회원·운영진 화면 이동, 위키 권한·오류 처리. 실패 상황을 의도적으로 만드는 테스트의 경고/오류 로그는 예상 결과다.
- JavaScript 구문 검사, Git diff 공백 검사 통과. 위키 문서 내부 링크가 모두 기존 제목에 연결되는 것을 확인했다.
- 합성 데이터만 쓰는 별도 로컬 서버에서 데스크톱 및 390px 폭의 이용 안내를 확인했다. 화면 배치 정상, 콘솔 경고·오류 없음. Chrome 자동화 확장은 탭 아이콘 위에 도구 배지를 덧씌우므로 원본 favicon 파일도 별도로 확인했다.
- 운영 위키 본문은 아직 수정하지 않았다. 추적 중인 `wiki_content` 파일은 검토용 소스 사본이며 배포만으로 실제 SQLite 문서가 바뀌지 않는다.

## Claude 검토

사용자는 Claude에 전체 사이트 검토 요청을 전달하라고 요청했다. 기존과 같은 Claude Code / Opus 5.5 High를 사용하려고 프롬프트와 선별 소스 사본을 준비했다.

- 프롬프트: 작업 루트 `outputs/CLAUDE_SITE_REVIEW_PROMPT.md`.
- 사본: `work/site-copy-review/claude-source/`, 기준 `3d6bb0d` (운영 앱 이후 문서 기록만 추가한 버전).
- 회원 데이터·DB·환경 파일·비밀키·Git 인증 제외. Read/Glob/Grep만 허용하며 Bash/Edit/Write/외부 도구를 금지하도록 구성했다.
- **자동 승인 검토에서 비공개 소스의 외부 전달 범위에 대한 구체적인 승인 부족으로 실행이 거절됐다. 사용자에게 선별 소스+프롬프트 전달 승인을 요청했으며 응답 대기 중이다. 아직 Claude에 전달하거나 답변을 받은 것이 아니다.**

## 승인 후 반영 원칙

1. Worker 정적 CDN과 미니 PC 앱을 같은 소스 버전으로 준비하고 사전 검사를 마친 후 배포 직전 사용자 승인을 받는다. Render·GitHub main·Supabase·카카오·도메인은 변경하지 않는다.
2. 위키 수정 직전 백업을 만들고 각 문서의 현재 revision과 본문 해시를 `work/site-copy-review/wiki-changes.json`의 기준과 비교한다. 다른 회원의 수정이 발견되면 중단하고 재검토한다.
3. 위키는 일반 엔진 편집 절차로 수정 이력을 추가한다. 초기 seed 재설치나 SQLite 본문 직접 덮어쓰기는 하지 않는다. 작성 양식은 실제 활동 기록으로 바꾸지 않는다.
4. 앱·CDN 검증 실패 시 직전 버전으로 복구한다. 문구를 되돌릴 때도 그 사이 회원 편집이 없는지 확인한 뒤 새 이력으로 복구하며 전체 DB를 과거 상태로 덮지 않는다.

재개 상태는 작업 루트 `outputs/site-copy-review-state.json`에서 확인한다. 이전 위키 설치/배포 스크립트는 다시 실행하지 않는다.
