## 확인 후 반영한 내용

- 추가 세미나를 매주 월요일 정례 활동처럼 설명하던 내 활동·투표 안내·학기 관리·출석 공지·일정 편집기의 문구를 수정했다.
- 버그 제보의 위치를 실제 계정 메뉴와 맞췄다. 오래된 관리자 화면/배포 절차/DB 용어/위키 엔진 이름 등 이용에 불필요한 설명을 정리했다.
- 수정 코드를 보관해야 하는 안내와 새 코드가 발급될 수 있다는 행동 안내는 유지하고, 4자리 PIN 전환 과정 설명만 줄였다. PIN 호환 기능은 변경하지 않았다.
- 비활성 계정은 로그인·위키 이용이 차단된다는 실제 결과를 안내한다. 권한 변경 후 재로그인이 필요하다는 문장은 다음 화면 요청부터 적용된다는 실제 동작에 맞췄다.
- `운영진 안내`, `회원 위키`, `동아리 소개(외부)`, `전체 운영`을 구분했다. 기존에 접근 가능한 officer에게도 회원 도움말의 운영진 안내 링크를 표시한다. 서버 권한은 변경하지 않았다.
- 내 활동의 이름 기반 조 편성 합계를 확정 출석으로 오인하지 않도록 `세미나 조 편성`으로 표시했다. 수치와 기록 계산은 바꾸지 않았다.
- 위키 가입 안내를 승인 후 재로그인으로 정리했다. 현재 학기 확인 실패 안내는 학기 없음/중복 모두에 맞는 문구로 수정했다.
- 회원 목록·상세·조 편성 화면에서 예외 원문을 그대로 보여주지 않고 사용자에게 필요한 재시도 안내를 표시한다. 서버 진단 로그는 유지한다.
- 발제문 페이지에 표시되는 실제 마감 시각은 그대로 두고, 미개설 회차가 포함되어 오해할 수 있는 `마지막 회차 기준`이라는 부가 설명은 제거했다.

## 기능 검토로 남긴 사항

| 항목 | 코드 확인 및 판단 |
|---|---|
| 미개설 추가 회차와 발제문 마감 | 마감에 비활성 회차를 포함하는 것은 현재 코드가 명시적으로 유지한 동작이다. 미개설 회차 제외 또는 세미나 전날 마감으로 바꾸면 운영 규칙이 달라지므로 이번 문구 정리에서는 변경하지 않았다. |
| 출석 미확인 목록 | `attendance_routes.py`의 pending_sessions에 비활성/휴회 필터가 없어 미개설 회차가 나올 수 있다. 필터 정리가 필요한 실제 후보이며, 출석 계산 변경 작업으로 분리한다. |
| 조 편성 첫 화면 | `/making_team`의 기본 day가 mon인 것을 확인했다. 직접 진입 시 활성 본 회차를 선택하도록 하는 개선이 필요하다. 이번에는 저장·선택 로직을 바꾸지 않았다. |
| 시험 주 필터 일관성 | 휴회 인식과 대시보드/캘린더 적용이 다르다. 기존 도서/기록을 숨기지 않도록 기준을 맞추는 별도 수정이 필요하다. |
| 비활성 확인과 오류 표시 | 현재 버튼은 즉시 저장되며 일부 JS가 서버 error 대신 message만 읽는다. 문구에는 차단 효과를 명시했고 확인창/오류 처리 변경은 후속 후보로 남겼다. |
| 내 활동 집계·속도 | 이름 기반 조 편성 집계와 전체 테이블 조회는 확정 출석과 구분해야 한다. 표시 명칭만 정정했으며 실제 조회 성능은 이번에 측정하지 않았다. |
| 학기 범위·옛 문서 API | 학기 참석 조회의 날짜 범위와 예전 /api/docs 접근은 별도 범위 확인이 필요하다. 기존 기록 접근을 임의로 막지 않았다. |

## 그대로 받아들이지 않은 지적

- **push-worker.js 누락**: 검토 사본에서 제외된 파일일 뿐, 실제 Git 저장소 루트에는 추적 중인 파일이 존재하며 라우트가 이를 제공한다. 파일 누락 결함으로 기록하지 않는다.
- **재가입 시 중복 계정 생성 단정**: 앞서 적용한 `members_social_id_unique_nonempty` 고유 인덱스가 검토 사본에 포함되지 않았다. 중복 계정이 쌓인다고 단정할 수 없다. 재시도 시 예외 처리/입력 보완은 별도 확인 대상이다.
- **현재 학기 없음으로 문구 고정**: 같은 코드 경로가 학기 기간 중복도 처리하므로 '진행 중인 학기가 없다'라고 단정하는 수정안은 채택하지 않았다.
- **운영진 위키 권한 예외·방학 정책·대표자 공개 범위**: 이미 정한 권한을 이 검토만으로 변경하지 않았다.

## 후속 검증과 상태

관련 Python 테스트 30개 재통과. 96개 템플릿 구문 검사 통과. 합성 오류를 주입한 회원 목록/상세 두 경로에서 내부 오류 내용이 응답에 나타나지 않는 것을 확인했다. officer의 도움말 링크와 실제 접근 권한이 일치한다.

위키는 읽기 전용 재조회 결과 문서 14개/이력 19개이며 13개 수정 대상의 기존 버전과 해시가 모두 일치했다. 실제 편집 직전에 다시 확인해야 한다. **이번 문구·탭 로고 개선은 아직 운영 미반영이다.** 배포 직전 승인 조건은 유지된다.
