매주 하는 일

1
도서·저자·안내 저장

세미나 운영의 해당 주 카드에서 한 번 저장하면 목요일·월요일 회차와 발제문, 연결된 기록에 함께 반영됩니다.

2
발제문 수집 열기

링크 복사 후 카톡방에 공유하고 제출 인원을 확인합니다. 발제문은 모임일부터 7일째 되는 날 자동으로 마감됩니다.

3
참석자 확정

목요일은 연락받은 불참자를 등록하고, 월요일은 신청자와 정원을 확인합니다.

4
조 편성 후 저장

전체 인원, 발제자 자동 연결, 만나면 안 되는 조합을 확인하고 결과를 저장합니다.

세미나 당일·직후

  • 실제 참석자와 조 편성 결과가 맞는지 확인
  • 연락 없이 빠진 사람은 해당 회차의 무단 불참으로 등록
  • 결과 화면 캡처 후 공지하고, 저장된 진행 기록 열기
  • 후기를 받을 때만 후기 링크를 만들고 공유
무단 불참자는 그 회차에서 “서로 만난 날짜·횟수” 계산에서도 자동 제외됩니다. 잘못 등록했다면 취소하면 만남 기록도 다시 계산됩니다.

회원 관리

회원 관리의 각 회원 행에서 활성·휴면·비활성 버튼을 누르면 즉시 저장됩니다.

활성

목요일 참석 대상·조 편성 후보

휴면

기록은 유지, 기본 명단 제외

비활성

졸업·탈퇴 등 장기 미활동

관리자 지정과 “만나면 안 되는 조합”은 권한이 있는 소수 관리자만 다룹니다. 관리자 변경 후에는 해당 회원이 다시 로그인해야 권한이 갱신됩니다.

학기 시작에 한 번

  • 새 학기를 만들고 시작일·종료일, 자동 생성된 목·월 날짜 확인
  • 전체 회원 상태 정리: 복귀자는 활성, 쉬는 회원은 휴면, 졸업·탈퇴는 비활성
  • 신입 회원의 이름·학번·학과·기수 입력 및 중복 계정 확인
  • 도서 일정 일괄 입력 후 날짜가 맞는지 확인
  • 세미나실 예약 현황과 월요일 기본 정원 확인
  • 운영진이 직접 로그인해 세미나 운영·회원 관리 권한 확인

학기 종료에 한 번

  • 세미나 진행 현황에서 도서명·발제자·조 편성 누락 확인
  • 출석 매트릭스를 학기로 필터링하고 엑셀 내려받기
  • 발제·벽돌책·소모임·행사 기록이 회원 프로필에 반영됐는지 표본 확인
  • 현재 학기를 삭제하지 말고 보관
  • 다음 학기 휴면·비활성 전환 대상 정리

연 1회 또는 운영진 인수인계 때

  • 실제 관리자 1~2명과 운영진 권한이 맞는지 확인
  • Supabase·Render·GitHub 소유자와 결제·복구 연락처 확인
  • 카카오 로그인 설정의 운영 URL과 담당자 확인
  • 최근 학기 출석 엑셀과 필요한 운영 문서를 운영진 전용 공간에 보관
  • 새 담당자가 테스트 회원으로 로그인해 주간 운영 한 번 실습
비밀번호·API 키·서비스 비밀값은 공개 위키나 단체 채팅에 적지 마세요. 공식 안내는 Notion 공개 위키, 민감한 인수인계는 운영진 전용 저장소를 사용합니다.

과거 기록을 수정할 때

  1. 세미나 진행 현황에서 해당 회차의 한 번에 편집을 누릅니다.
  2. 도서명·날짜·발제자·조 편성을 한 화면에서 확인하고 저장합니다.
  3. 일정에 연결된 기록의 도서명은 같은 주의 목·월 일정과 발제문에도 동기화됩니다.
  4. 조 편성을 바꾸면 전체 만남 횟수·날짜가 다시 계산됩니다.

그날 저장하지 못한 회차만 “과거 세미나 수동 추가”를 사용하세요. 이미 있는 회차를 다시 만들면 중복 기록이 생깁니다.

문제가 생겼을 때

  1. 새 회차를 만들거나 기존 기록을 삭제하지 말고, 먼저 새로고침 후 같은 문제가 반복되는지 확인합니다.
  2. 화면 아래 버그 제보에 날짜, 화면 이름, 누른 버튼, 기대한 결과를 적습니다.
  3. 버그 제보 관리에서 접수 내용을 확인합니다.
  4. 배포 후에는 세미나 운영 화면과 공개 발제문 링크를 각각 확인합니다.
